Guides

Downloadable guides for family trips and days closer to home. Nothing is for sale until a guide is actually finished. When it is, the buy button leaves this website for a checkout link we set on that guide.

How buying works

We do not run a cart and we never see your card number. Each guide has a buyUrl in its file. That link is the whole checkout: a digital-download shop, a payment page, or a file host we choose later.

If a link pays us a commission, the guide is marked as an affiliate and the disclosure on this page is switched on. Right now that disclosure is off, because there is nothing to disclose.
