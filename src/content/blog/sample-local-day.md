> **Sample draft.** This file shows how a local activity is written up. It is not a trip we took. It stays off the live site while `draft` and `sample` are true.

## Before you publish

Replace the title, description, date, hero, destination, and region with the day we actually had. Remove `draft` and `sample` only then. Delete this banner.

## How the day went

Write the day in the order it happened. First names only. Include the parts that were short, rainy, or grumpy, not just the nice half hour.

## Practical notes

- How we got there
- What it cost, if anything
- How long we stayed
- What we would repeat with Harrison, Sullivan, and Maeve

## The film

If this day has a YouTube video, add `youtubeId` in the frontmatter using the 11-character id from the video URL. The story will embed that film and link to the channel. Leave the field off when there is no film. Do not paste an unrelated video id.
