## Same fields, different file

Use `.md` when the story is prose. Use `.mdx` when you want a component in the body. The frontmatter does not change.

A day trip uses `tripType: day-trip`. A local Toronto day uses `tripType: local`. The blog index can filter on either, and on the region.

The destination in this file is deliberately fictional, so a destination page is not created for it. Destination pages are built only from posts that are actually published.

## A short list of the format

- Title, description, and date
- Hero image and alt text
- Destination and region, spelled consistently
- Trip type
- Ages that day for Harrison, Sullivan, and Maeve
- Tags
- Optional YouTube id
- `draft: true` until the story is real
